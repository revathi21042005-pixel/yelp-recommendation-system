# Yelp Recommendation System
A restaurant recommendation system built using KNN and TF-IDF.

## Tech Stack
- Python
- Pandas, Scikit-learn
- TF-IDF Vectorizer
- K-Nearest Neighbors

## Features
- Recommends restaurants based on user reviews
- Uses collaborative filtering
